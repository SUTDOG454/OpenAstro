# Merged Signals and Indicators

This package catalogs all signal/indicator source artifacts from the existing all-sources inventory and maps explicit ASTO and economic indicator definitions into a shared, provenance-bearing schema. Exact semantic duplicates are merged only when their normalized payloads are identical. Conflicting versions remain as separate variants in `conflicts.json`.

Source artifacts are cataloged without executing embedded code. Astrological interpretations and market/company scoring rules remain source-derived or methodology-bound. They are not empirical forecasts, investment advice, or causal claims.
