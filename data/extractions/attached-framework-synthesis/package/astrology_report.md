# Attached Framework Synthesis Report

## Scope

This package preserves and maps eleven user-provided artifacts spanning house definitions, ASTO framework metadata, chart synthesis prose, Arabic Parts, transit-strength methodology, economic and market timing configurations, asteroid keyword interpretations, and sensitive sexual-archetype material. The sources are treated as untrusted, source-derived material. No embedded code or deployment instructions were executed.

## Evidence classes

| Class | Handling |
|---|---|
| Source-derived | Raw attachments, house definitions, ontology, chart types, signal labels, asteroid keyword text, and economic configuration candidates. |
| Methodology-bound | Arabic Parts formulas, transit dignity and house-affinity rules, repeated-confirmation logic, and economic scoring formulas. |
| Computed | None generated from birth/event data in this synthesis; no chart calculation was requested with complete settings. |
| Pending review | Production-ready claims, external references, source licenses, conflicting schemas, sensitive content, and semantic promotion into canonical registries. |

## Findings

The inventory contains **11 sources**: **9 parseable JSON objects/lists**, **1 chart-synthesis Markdown/prose source**, and **1 malformed JSON source**. The economic market system appears in several versions. The 04 and 08 files are exact normalized duplicates and were preserved rather than deleted. Other economic files contain materially different indicators, field names, and module coverage, so they remain competing candidates.

The ASTO source declares 19 chart types, 7 explicit calculations, 15 signals, and a repeated-confirmation weighting model. The house framework contains 12 house definitions. The Arabic Parts source contains 10 part formulas and a transit-strength methodology with dignity scores, aspects, accidental modifiers, and planetary house affinities. The asteroid source is retained as source-derived interpretation content and is not automatically promoted into the canonical entity registry.

## Safety and review boundaries

The sensitive sexual-archetype source is preserved in raw form but excluded from default normalized retrieval. Its JSON is malformed because of an unescaped quotation mark in the notes field; it was not silently repaired. The Aries chart synthesis contains deterministic and health-adjacent language, but no chart source data or calculation settings were supplied, so it remains prose only. Economic and market timing material is configuration, not validated financial analysis or investment advice.

## Canonical integration

The canonical registry and calculation catalog remain owned by `astrology-data-unifi`. This package maps attached concepts to candidate records and records formulas, source IDs, statuses, settings requirements, discrepancies, and coverage gaps. Semantic changes to traditions, orbs, dignity rules, scoring weights, asteroid registrations, or financial research methods require explicit review.

## Validation evidence

The package includes `source_inventory.json`, `source_analysis.json`, `normalized_records.json`, `definitions.json`, `calculations.json`, `methodology_registry.json`, `discrepancy.json`, `coverage_gap_register.json`, `astrology_master.json`, `manifest.json`, and `validation_report.json`. All raw source files are hash-recorded. No source code was executed.
