# Company-Research Source Extractions

This directory contains provenance-preserving source extracts located during a search of the user’s accessible GitHub repositories and the user-provided economic-market configuration.

The selected `finance-query` files expose company quote, fundamentals, financial-data, and research models. They are Rust source extracts from the MIT-licensed repository at [SUTDOG454/finance-query](https://github.com/SUTDOG454/finance-query), pinned to commit `e95b3e0185d170324eaae216c8db302d841e29ae`. The repository license is preserved beside the extracts.

The user-provided configuration is retained as a separate reference artifact with no independently declared license. It must not be redistributed or treated as an authoritative external source without the user’s direction.

These files are **source extracts**, not executable OpenAstro modules. They have not been adapted, compiled, or executed. The manifest records hashes, source metadata, deduplication policy, validation status, and the review queue. Any future TypeScript adapter or company-research module must define a canonical schema, preserve field-level provenance, verify license compatibility, and add module-specific Vitest or Jest tests before promotion.
